# Trip2Vegas.com - Las Vegas Travel Agency

**Status**: 🚧 In Development
**Live Site**: https://trip2vegas.com
**Type**: Static Website (HTML/CSS/JS)

## 🎰 Project Overview

Premium Las Vegas travel agency website offering curated tours, shows, and experiences.

### **Business Type**
- Las Vegas travel agency
- Tours: Grand Canyon, Hoover Dam, Red Rock Canyon, Area 51
- Shows: Cirque du Soleil, Magic shows, Concerts
- Adventures: Helicopter rides, Exotic cars, Shooting ranges
- Custom travel packages

### **Target Audience**
- Turkish tourists (primary market)
- International travelers
- Vegas first-timers and experienced visitors

---

## 🎨 Design System

### **Vegas Luxury Theme**
- **Primary**: Gold (#FFD700) - Buttons, accents, highlights
- **Secondary**: Deep Black (#0A0A0A) - Backgrounds
- **Accent**: Vegas Red (#DC143C) - CTAs, urgent offers
- **Text**: White on dark, Dark Gray on light

### **Typography**
- **Headings**: Playfair Display or Cinzel (elegant serif)
- **Body**: Montserrat or Lato (modern sans-serif)

## 📝 Development Setup

### **Prerequisites**
- Git
- Any code editor (VS Code recommended)
- Modern web browser

### **Local Development**
```bash
# Clone repository
git clone https://github.com/yourusername/trip2vegas.git
cd trip2vegas

# Open in browser
# Just open index.html in your browser
# Or use a local server:
python -m http.server 8000
# Visit: http://localhost:8000
```

### **Deployment**
Automatic deployment via GitHub Actions:
```bash
git add .
git commit -m "Your message"
git push origin main
# Auto-deploys to GitHub Pages
```
