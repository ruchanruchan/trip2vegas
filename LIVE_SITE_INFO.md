
## 🚨 Troubleshooting

### **If Site Doesn't Load:**
1. Check URL is correct: https://purple-cliff-0bd29300f.4.azurestaticapps.net
2. Clear browser cache (Ctrl+Shift+R)
3. Try different browser or incognito mode
4. Check GitHub Actions for deployment errors

### **If Deployment Fails:**
1. Go to: https://github.com/ruchanruchan/trip2vegas/actions
2. Click failed workflow run
3. Check logs for errors
4. Fix issue and push again

### **If Language Toggle Doesn't Work:**
1. Clear browser cache and localStorage
2. Try different browser
3. Check browser console (F12) for JavaScript errors
